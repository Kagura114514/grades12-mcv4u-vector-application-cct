# Vector Applications CCT site

A static, GitHub Pages-ready MCV4U Course Culminating Task site. The Learn section contains concise notes and original worked examples following sections 7.1-7.7 of Nelson Calculus and Vectors 12.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload all files and folders in this folder. Keep the `lessons` folder beside `index.html` so the lesson links work.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main`, then `/ (root)`, and save.
4. GitHub will provide the public site address after deployment.

Before submitting, replace remaining placeholders, add your video lessons and typed homework and assessment solutions, and verify the site against your teacher's rubric. Cite any external images, videos, or resources you add.
