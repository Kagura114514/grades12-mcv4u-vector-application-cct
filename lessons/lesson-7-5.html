Scalar & Vector
Projections

01 · What is a projection?

Measure the part along a direction.

The projection of a onto b answers how much of a points along b. The scalar projection is a signed number. The vector projection points along b (or opposite it if the scalar component is negative).

If a and b are perpendicular, the projection of a onto b is zero. The vector b must be nonzero because its direction defines the projection axis.

02 · Formulas

Use the dot product.

Scalar component of a along b:
compb a = (a · b) / |b|

Vector projection of a onto b:
projb a = ((a · b) / |b|²)b

The scalar component is also |a|cos θ, where θ is the angle between a and b.

03 · Original worked example

Project onto the x-direction

Let a = (3, 4) and b = (1, 0). Find the scalar and vector projections of a onto b.

1Compute a · b = 3(1) + 4(0) = 3, and |b| = 1.
2Scalar projection: compb a = 3/1 = 3.
3Vector projection: projb a = (3/1²)(1, 0) = (3, 0).
4The result matches the horizontal component of a, since b points along positive x.

04 · Practice prompt

Check your understanding

Let a = (2, 5) and b = (0, 1). Find both projections of a onto b. Explain why the scalar projection is 5.

Show a hint

Here b is a unit vector in the positive y-direction.
